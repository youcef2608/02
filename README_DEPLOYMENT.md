# تعليمات تثبيت وبناء تطبيق أثر | Athar Mobile App

تطبيق أثر هو تطبيق Android حديث مكتوب بلغة Kotlin مع Jetpack Compose، ومربوط مباشرة مع السيرفر المحلي وقاعدة بيانات Supabase.

---

## 1. تشغيل التطبيق عبر Android Studio

1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد المجلد:
   `H:\02`
3. انتظر انتهاء مزامنة ملفات Gradle (Sync Project with Gradle Files).
4. اضغط على زر **Run** الأخضر أو اختصار `Shift + F10` لتثبيت وتشغيل التطبيق على الهاتف المتصل أو المحاكي (Emulator).

---

## 2. بناء ملف APK للتثبيت المباشر على أي هاتف (Manual / CLI Build)

من خلال موجه الأوامر في مجلد المشروع `H:\02`، نفذ الأمر التالي:

```bash
# إنشاء حزمة Debug APK جاهزة للتثبيت المباشر
./gradlew assembleDebug
```

سيتم توليد ملف APK مباشرة في المسار:
`H:\02\app\build\outputs\apk\debug\app-debug.apk`

يمكنك نسخ هذا الملف وتثبيته مباشرة على أي هاتف يعمل بنظام Android.

---

## 3. مميزات التطبيق الحالية
- **تسجيل دخول وتسجيل حساب جديد**: حفظ دائم في قاعدة البيانات والذاكرة المحلية.
- **تحديد الصلاحيات**: التبديل بين حساب "متطوع ميداني" وحساب "جمعية معتمدة".
- **مزامنة فورية**: استقبال النداءات الميدانية من الموقع والمزامنة اللحظية للاستجابات والملاحظات.
- **خريطة تفاعلية ومساعد ذكي**: دعم الملاحة الميدانية واستشارات الذكاء الاصطناعي.
